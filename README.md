## Summary of the project;

In this project the main goal was to produce an AI chatbot for mental health. 

Firstly, a mall amount of data and Nous Hermes 2 Mistral was used. 
For comparison and getting insights about the results we used base model to get responses for specific prompts from the data. 
Later, the same prompts used with the fine tuned model to get responses again. This way we were able to compare the base and the fined tuned model. 

Since the results were not that satisfiying, another model Llama 3 with a bigger amount of data was put to the same process.
